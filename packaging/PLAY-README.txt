NEURON NOODLE FIELD 0.4.0 — WINDOWS X64

Extract this entire ZIP to a normal folder, then double-click Play.cmd or
NeuralPlayer.exe. Keep the files together. No Python, .NET installation,
administrator access or command prompt is needed.

Click Execute image (or Right arrow) for one update. Space runs or pauses.
Open image (O) lets you select examples/and.tiff or examples/center.gif.
OR spreads; AND extinguishes a single seed; CENTER holds the seed in place.
The difference is in each image's model or operator graph.

Export (E) writes a new TIFF and GIF with the current program, model, runtime,
and updated field state. Reopen either output to continue. Reload (R) returns
to the opened image's original state. Existing output files are preserved.

An ordinary image viewer only displays these files. This player reads a
hash-approved interpreter assembly from pixels and executes it using the
included .NET bootstrap. CPU execution is not physical optical computation.
